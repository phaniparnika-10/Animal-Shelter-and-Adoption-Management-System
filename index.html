About the project

The Animal Shelter & Adoption Management System is a Java-based mini project that manages animal records and simplifies the adoption process. It replaces a paper register with a small program that knows which animals are available, who the adopters are, and which adoptions are complete.

The project is also a working example of object-oriented programming. Each part of a real shelter is modelled as a class, and the code shows the four core ideas of OOP in practice.

  • Encapsulation
  • Inheritance
  • Polymorphism
  • Abstraction

  • Search

OOP concepts in the project

The four pillars of object-oriented programming, and where each one appears in the shelter code.

Encapsulation

Data members such as an animal's ID, name and age are private. Other classes reach them only through public methods, so the data stays protected and consistent.

  • private fields
  • public getters

Inheritance

Dog, Cat and Bird inherit common properties and behavior from the Animal class, so shared code is written once and reused.

  • Dog extends Animal
  • Cat extends Animal
  • Bird extends Animal

Polymorphism

Each animal class provides its own version of methods such as getType() and makeSound(). The same call gives a different result for a Dog, a Cat or a Bird.

  • getType()
  • makeSound()

Abstraction

An abstract Animal class defines the behavior every animal must have, while each specific type supplies the details.

  • abstract class Animal

How an adoption works

Every adoption follows the same six steps, from registering the animal to saving the final record.

  1. 1

    Register Animal

    Add the animal's ID, name, breed and age. It starts as available.

  2. 2

    Register Adopter

    Store the adopter's ID, name and phone number.

  3. 3

    Select Animal

    Find the animal the adopter wants by its ID.

  4. 4

    Check Availability

    Make sure the animal has not already been adopted.

  5. 5

    Complete Adoption

    Link the animal to the adopter and mark it as adopted.

  6. 6

    Save Adoption Record

    Add the adoption, with its date, to the list of records.

Project architecture

The program is built in layers. Each layer only talks to the one below it.

  1. User

    Chooses what to do from the console menu.

  2. Main Program

    Starts the application, shows the menu and reads the user's input.

  3. Shelter Management

    The Shelter class holds the logic for adding, searching, checking availability and completing adoptions.

  4. Animal / Adopter / Adoption Classes

    Model the real-world objects and keep their data.

  5. ArrayList Collections

    Store all animals, adopters and records in memory.
